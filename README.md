## ✨ Features

* **Light & Dark Mode Toggle:** Seamless, fluid transitions between themes using custom Tailwind CSS configuration.
* **Responsive Design:** Fully optimized for mobile, tablet, and desktop viewing.
* **Modern UI/UX:** Clean aesthetics, subtle glowing backgrounds, and smooth scroll navigation.
* **Component-Based Architecture:** Modular, easy-to-maintain code structure built with modern React.

## 🛠️ Tech Stack

* **Frontend:** React.js, JavaScript (ES6+)
* **Styling:** Tailwind CSS (Custom configuration for dual-theme support)
* **Icons:** React Icons
* **Build Tool:** Vite
